# Deep dive: what actually makes a small-model CAD agent work (2026-07-11)

Trigger: one flange spec ("60mm OD × 8mm, Ø20 bore, 4× Ø5 on a Ø42 circle, 1mm chamfer")
run 5× through the v5 agent, 2× through earthtojake's text-to-cad plugin (Claude as coder),
and 2× through a jerry-rig harness (`~/CAD/experiments/2026-07-11-7b-on-text-to-cad/`)
where the LOCAL 7B drives the plugin's tooling. Every claim below was measured today.

## The two decisive experiments

1. **Bare 7B on earthtojake's stack: 0/4 turns produced runnable code.** The plugin
   assumes a frontier coder — no API patches, no inline auto-fix, no examples. The 7B's
   build123d is too broken to even crash usefully.
2. **7B + ONE style-only worked example + raw spec text: converged turn 1, perfect part**
   (Ø5×4 @ r21, Ø20 bore, chamfer landed). The same model that failed the same spec five
   times inside v5 that morning.

Conclusion: the gap was never model quality. Two v5 layers were actively hurting:
the coder never saw the user's words (brief paraphrase only), and the injected gold
example carried copyable numbers (both 7B AND 30B built the reference's six Ø6 holes).

## Layer-by-layer verdict

| Layer | Verdict | Evidence / action |
|---|---|---|
| `_CODE_PATCHES` + N1 inline auto-fix | **KEEP — load-bearing.** | Bare 7B without them: 0/4 runnable (harness attempt #1). This is what earthtojake lacks for small models. |
| Raw spec → coder | **FIXED today.** `generate_code(brief, spec)` puts the verbatim request first, marked authoritative. | Harness one-shot vs 5 brief-fed failures. |
| Brief (qwen3:8b) | **DEMOTE, don't delete.** It is an *acceptance-criteria extractor*, not the coder's input. Its real value: `expected` block (feeds the gate), triage, helper routing, N2 questions, section detection. Its paraphrase as sole coder input was the bug. | Kept as structured support under the verbatim spec. | Few-shot retrieval | **REFRAME: style library, numbers stripped.** Injected code now has every literal → `<DIM>`; prose warnings provably failed. Think image-search: "what does a flange look like", never "what were its dimensions". | 30B copied gold's 6×Ø6 into a 4×Ø5 spec. A/B with `--no-fewshots` on the next benchmark to confirm the lift survives neutralisation. |
| `rate 1-5` corpus path | **REDUNDANT — replace with Stage C auto-promotion.** The gate now *measures* correctness; a gate+critic-verified converged build is a better promotion signal than a human star. Keep `rate` only as an optional human veto/boost. | User call, 2026-07-11. Stage C is already on the roadmap; wire it to `accepted_via` + zero `[spec]` advisories. |
| Verification gate | **STRONGEST LAYER — keep investing.** Hole groups (Ø×count×circle), corroborated hard-fails, `[spec]` advisories vetoing accept-via-gate. | Caught wrong-size holes in 4/4 live builds where the critic passed 2 of them. |

| Honest convergence | **CLOSED today.** No accept while a measurement contradicts a spec number. | The 16mm-thick no-hole "converged" flange, now impossible. |

## The optimal shape (what this architecture is converging to)

A small-model CAD agent needs exactly four things:
1. **Runnable-code scaffolding** (patches, auto-fix, one style example) — the floor.
2. **The user's numbers, verbatim, un-paraphrased** — the spec is the contract.
3. **A tape measure, not a reviewer** — deterministic per-feature measurement feeding
   exact repair messages ("measured Ø8×4, spec says Ø5").
4. **Honest exits** — converge only when measurements agree with the spec; escalate or
   admit failure otherwise.

Everything else (brief, critic, retrieval, rating) is auxiliary and must pay rent in
A/B-measured lift or shrink.
