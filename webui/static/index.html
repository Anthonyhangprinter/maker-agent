What should we build?

Good prompts say Size (envelope in mm) · Specs (counts + diameters) · Surfaces (which face) · Symmetry (patterns/spacing). With a photo: shape and proportions come from the image, absolute sizes still come from your words.
One build at a time (single GPU) — you'll see “waiting for GPU” if another agent is building. In-flight builds are lost if the server restarts.
